💡 How to Use This Dashboard
1. Search for a City: Type any city name (e.g., "London", "Tokyo", "Sydney") and click Search to fetch real-time weather data from OpenWeatherMap API.
2. Current Weather: See the current temperature, weather condition, humidity, wind speed, and pressure for your selected location.
3. Hourly Forecast: Check 24-hour forecast with temperature and precipitation chances for each hour.
4. 7-Day Forecast: Plan ahead with extended forecast showing daily high/low temperatures and weather conditions.
5. Dynamic Styling: Icons and colors update based on weather conditions (sunny, cloudy, rainy, stormy).
